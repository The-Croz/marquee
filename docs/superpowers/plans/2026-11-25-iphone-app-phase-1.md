# iPhone app · Phase 1 (Foundations) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Josh can install Marquee on his iPhone, sign in (password, Pocket ID or Plex) at his Home or Outside address, and see Home and Activity (downloads, requests) with approve / turn down, in the D + E look.

**Architecture:** The server learns bearer tokens for app sessions, a `devices` table, and a one-time code to finish browser sign-ins into the app. A server test writes real JSON responses as fixtures that the Swift package decodes in its own tests. The iOS app is SwiftUI (iOS 26+) in `apps/ios`: `MarqueeKit` (Swift package: models, API client, token store, no UI) and the `Marquee` app target (design system and screens), generated by XcodeGen.

**Tech Stack:** Hono/Node 22/SQLite/Drizzle/vitest (server); Swift 6, SwiftUI, Observation, URLSession, AuthenticationServices, XcodeGen, Swift Testing (iOS).

**Spec:** `docs/superpowers/specs/2026-11-25-iphone-app-design.md` (read it first; this plan is its Phase 1). Mockups: "iPhone app · D + E" row on https://claude.ai/artifact/68JrXjWP9SqwwzaUoxcPWT (`AppHome`, `AppDownloads`, `AppRequests`, `AppMe`).

**Not in Phase 1** (later plans): Discover, Library, title pages, Search, Calendar (phase 2); push, notification extension, Live Activity, widget targets (phase 3); Watching, Manage, TestFlight (phase 4). Their tabs are not shown yet.

## Global Constraints

- iOS deployment target **26.0**; Swift 6 language mode, strict concurrency; no third-party Swift packages.
- Signing: `DEVELOPMENT_TEAM = 5BHPMRU3T8` (Josh's personal team) set explicitly in `project.yml`; never `P73FA44C6D` (work team), never automatic team selection. Bundle id `app.marquee.ios`.
- App sessions slide like web sessions but last **180 days**; web sessions stay **30 days** (`SESSION_TTL`).
- App sign-in codes live **60 seconds**, single use.
- All writes are JSON (`Content-Type: application/json`), app included.
- Migrations append-only; update `schema.ts` and `UNDO_NEWEST` in `test/system.test.ts`.
- Tokens never appear in logs, URLs other than the one-time `marquee://` code, or API responses other than the sign-in response itself.
- Words from `docs/GLOSSARY.md`; every failure shows a plain label and what to do. No arr or qBittorrent jargon on screen.
- Colors (exact): ink `#0A0C10`, panel `#12151C`, raised `#1A1F29`, line `#1E2430`, line-strong `#2E3543`, text `#F3F4F6`, soft `#C3CAD5`, muted `#A3ACBA`, dim `#8A93A3`, amber `#F2B33D`, amber-hi `#FFD27A`, amber-ink `#1A1206`, blue `#6AA6FF`, teal `#4FD1C5`, warn `#FF9E6B`. Dark only.
- Instrument Serif for film/show titles only; SF Pro (system font, Dynamic Type) for everything else. 44pt touch targets; every icon-only button has an accessibility label.
- TMDB image sizes: posters `w342` (rows, grids), `w185` (list rows), backdrops `w1280`, base `https://image.tmdb.org/t/p/`.
- Downloads and Home refresh every **5 s** while on screen.

## Review Focus

1. **Signed out under the app** (token expired, or "Sign out this phone" from the web): any 401 sends the app back to sign-in with "You were signed out. Sign in again." and clears the stored token. (Task 8 test, Task 10 behavior)
2. **Pangolin's sign-in in the way**: an HTML answer where JSON was expected shows "Pangolin's sign-in is in the way. In Pangolin, add a rule to the Marquee resource that skips sign-in for /api/*." (Task 8 test)
3. **Leaving home Wi-Fi**: Home address unreachable → the same request is retried once at the Outside address, and the Outside address is used until Home answers again on the next foreground. (Task 8 test)
4. **An older Marquee without app sign-in**: login answers without a `token` → "This Marquee is too old for the app. Update it to <min version> or newer." (Task 8 test)
5. **Members and kids signing in**: kids get no Activity tab; members get Activity with Requests only (their own); a 403 never shows as a crash or blank screen. (Task 11 test)
